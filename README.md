# ICA Startup Competition — Landing Page

Event landing page built for a 200-person startup competition hosted by ICA (InnovateConnect Alliance), a University of Melbourne–affiliated tech community. Attendees included government representatives, VCs, university academics, and tech executives.

Built as part of running the community's operations as COO — from a ~10-person volunteer team to a recurring events cadence and this competition.

Built with Next.js.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.
